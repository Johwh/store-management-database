# 🛒 Store Management Database

Projeto de banco de dados desenvolvido em SQL simulando um sistema de gerenciamento de loja.

O objetivo deste projeto é praticar conceitos fundamentais de bancos de dados relacionais, modelagem de tabelas e consultas SQL utilizadas no dia a dia de desenvolvimento e análise de dados.

---

# 📚 Conceitos Praticados

- Criação de tabelas
- Relacionamentos entre tabelas
- Primary Keys (PK)
- Foreign Keys (FK)
- INNER JOIN
- GROUP BY
- HAVING
- CASE
- COUNT
- AVG
- ORDER BY
- WHERE
- Modelagem relacional
